# Множественная линейная регрессия

## Теория

### Что это?

Множественная линейная регрессия позволяет оценить связь **сразу нескольких независимых переменных (НП)** с **одной зависимой переменной (ЗП)**.

$$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_k x_k + \varepsilon $$

### Главное преимущество перед корреляционной матрицей

Корреляционная матрица показывает только **парные связи**, но не учитывает, что переменные могут быть связаны между собой.

**Регрессия выделяет уникальный эффект каждой переменной** — мы можем узнать связь конкретного показателя с ЗП, **отсеяв альтернативные объяснения**.

### Пример

Корреляция цены автомобиля с мощностью двигателя может быть высокой, но:

- Мощность коррелирует с объёмом двигателя
- Мощность коррелирует с массой автомобиля

**Регрессия покажет:** какой вклад вносит именно мощность, **очищенная** от влияния других переменных.

## Оценка качества модели

### Коэффициент детерминации ($R^2$ и Adjusted $R^2$)

| Метрика | Что показывает | Проблема |
|---------|----------------|----------|
| $R^2$ | Доля дисперсии ЗП, объяснённая моделью | Растёт с добавлением любых предикторов |
| **Adjusted $R^2$** | $R^2$ с поправкой на число предикторов | Штрафует за бесполезные переменные |

### Информационные критерии

| Критерий | Формула (упрощённо) | Что делает |
|----------|---------------------|-------------|
| **AIC** (Akaike) | $-2 \ln(L) + 2k$ | Баланс качества и сложности |
| **BIC** (Bayesian) | $-2 \ln(L) + k \ln(n)$ | Более строгий, чем AIC |

Чем **меньше AIC/BIC**, тем лучше модель (при прочих равных).

### Метрика RMSE (Root Mean Square Error)

Оценивает, **насколько сильно модель ошибается в предсказаниях**.

$$ RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2} $$

- Интерпретация: в среднем модель ошибается на RMSE единиц
- Единицы измерения те же, что у ЗП

## Диагностика модели

### Мультиколлинеарность

**Ситуация:** очень сильная связь между несколькими независимыми переменными.

| Влияние на предсказания | Влияние на интерпретацию |
|------------------------|--------------------------|
| ❌ **Не влияет** | ⚠️ **Усложняет или портит** |

**Как обнаружить:**
- VIF (Variance Inflation Factor) > 5-10
- Большие стандартные ошибки коэффициентов
- Нестабильные коэффициенты при изменении набора переменных

**Как решить:**
- Удалить одну из коррелирующих переменных
- Объединить их в один признак (PCA, факторный анализ)

### Допущения линейной регрессии

| Допущение | Что проверять | Чем грозит нарушение |
|-----------|---------------|----------------------|
| Линейность | Scatter plot | Неверные выводы |
| Нормальность остатков | QQ-plot, гистограмма | Проблемы с p-value |
| Гомоскедастичность | График остатков | Ошибки в значимости |
| Независимость ошибок | Durbin-Watson | Проблемы с временными рядами |

## Statsmodels vs Sklearn

| Библиотека | Лучше для | Особенности |
|------------|-----------|-------------|
| **statsmodels** | Статистического вывода | Подробные summary, p-value, доверительные интервалы |
| **sklearn** | Предсказаний | Скорость, кросс-валидация, пайплайны |

```python
# Statsmodels — для интерпретации
import statsmodels.api as sm
model = sm.OLS(y, X).fit()
print(model.summary())

# Sklearn — для предсказаний
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)
predictions = model.predict(X_new)
```

## Два подхода к регрессии

### 1. Статистический вывод (инференс)

**Цель:** понять, как переменные влияют на результат.

- Вопросы: "Увеличивает ли мощность двигателя цену?"
- Важны: p-value, доверительные интервалы, интерпретация коэффициентов
- Инструмент: **statsmodels**

### 2. Предсказание (ML)

**Цель:** максимально точно предсказывать новые значения.

- Вопросы: "Какая будет цена у этого автомобиля?"
- Важны: RMSE, R² на тестовой выборке
- Инструмент: **sklearn**

Линейная регрессия — это **мостик между статистикой и ML**.
