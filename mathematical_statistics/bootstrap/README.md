# Bootstrap — непараметрический метод оценки доверительных интервалов

## Теория

### Проблема

До этого мы работали главным образом со **средним**: t-тест, ANOVA, линейная регрессия — всё это проверяет различия в **средних значениях**.

**А что, если нужно оценить значимость различий в:**

- Медианах?
- Квантилях (например, 90-й перцентиль)?
- Других сложных метриках?

**Проблема:** Центральная предельная теорема (ЦПТ) для таких случаев **не гарантирована**, доверительные интервалы просто так не построишь.

---

### Решение: Bootstrap

**Bootstrap (бутстрап)** — своего рода "серебряная пуля" в аналитике для таких ситуаций.

> Вместо того чтобы полагаться на готовые теоретические распределения, бутстрап полагается **исключительно на сами данные**.

---

## Как работает бутстрап

### Основная идея

Мы **имитируем** ситуацию проведения одного и того же эксперимента много-много раз, считая для каждого симулированного эксперимента нужную метрику, и уже по распределению этой метрики строим доверительный интервал.

### Симуляция выборки

```python
# df — наш датафрейм
df.sample(frac=1, replace=True)
```

| Параметр | Значение | Что делает |
|----------|----------|------------|
| `frac=1` | 100% строк | Берём столько же строк, сколько было изначально |
| `replace=True` | С повторением | Один и тот же ряд может быть взят несколько раз |

**Результат:** "новая" выборка немного отличается от исходной, но сохраняет размер и информацию.

---

## Алгоритм бутстрапа

```python
# Сюда будем складывать результаты
medians = []

# Повторяем процесс 10000 раз
for i in range(10000):
    # Симулируем выборку
    sample_data = df.sample(frac=1, replace=True)
    
    # Считаем показатель (в данном случае медиану)
    sample_median = sample_data.value.median()
    
    # Добавляем результат в список
    medians.append(sample_median)
```

**Результат:** распределение медиан (или любой другой метрики).

---

## Построение доверительного интервала

Простейший способ — взять **квантили** полученного распределения.

Для **95% доверительного интервала**:
- Нижняя граница = 2.5% квантиль
- Верхняя граница = 97.5% квантиль

```python
lower = pd.Series(medians).quantile(0.025)
upper = pd.Series(medians).quantile(0.975)
```

**Почему 2.5% и 97.5%?**  
95% доверительный интервал оставляет по 2.5% хвоста с каждой стороны.

## Сравнение групп

### Вариант 1: Сравнение доверительных интервалов

Строим доверительные интервалы отдельно для контрольной и тестовой группы и смотрим, насколько они перекрываются.

### Вариант 2: Разница между группами (предпочтительнее)

Внутри бутстрапа считаем **разницу** между группами и сохраняем её.

```python
diffs = []

for i in range(10000):
    sample_control = control.sample(frac=1, replace=True)
    sample_test = test.sample(frac=1, replace=True)
    
    diff = sample_test.median() - sample_control.median()
    diffs.append(diff)

# 95% доверительный интервал для разницы
lower = pd.Series(diffs).quantile(0.025)
upper = pd.Series(diffs).quantile(0.975)
```

**Критерий значимости:** доверительный интервал **не должен включать 0**.

## Готовые реализации в Python

### 1. scipy.stats.bootstrap (с версии 1.7.0)

```python
from scipy.stats import bootstrap

# Для одной группы
result = bootstrap(
    (data,),                    # данные (кортеж)
    statistic=np.median,        # функция для расчёта метрики
    n_resamples=9999,           # количество симуляций
    confidence_level=0.95,      # уровень доверия
    method='BCa'                # метод (BCa — предпочтительный)
)

print(result.confidence_interval)
```

**Ключевые аргументы:**

| Аргумент | Описание |
|----------|----------|
| `data` | Данные в виде списка или кортежа |
| `statistic` | Функция для расчёта метрики |
| `n_resamples` | Количество симуляций (по умолчанию 9999) |
| `confidence_level` | Уровень доверия (по умолчанию 0.95) |
| `method` | Алгоритм расчёта CI |

### 2. pingouin.compute_bootci

```python
import pingouin as pg

result = pg.compute_bootci(
    data,                       # данные
    func=np.median,             # функция для расчёта метрики
    n_boot=10000,               # количество симуляций
    confidence=0.95             # уровень доверия
)

print(result)
```

### 3. bootstrapped (от Facebook/Meta — запрещённая в РФ организация)

Ориентирован на применение в индустрии. Содержит ноутбуки-демонстрации.

### 4. wildboottest

Позволяет оценивать статистическую значимость коэффициентов регрессионной модели с помощью бутстрапа.

**Особенность:** реализует **"дикий бутстрап"** (wild bootstrap) — более устойчивый к нарушениям гомоскедастичности.

```python
from wildboottest import wildboottest

# Работает вместе со statsmodels
result = wildboottest(model, x='horsepower')
```

## Когда применять бутстрап

| Ситуация | Почему бутстрап |
|----------|-----------------|
| Сравнение медиан | ЦПТ не работает, нет готовой формулы |
| Сравнение квантилей | Аналогично |
| Сложные метрики (например, отношение) | Нет теоретического распределения |
| Маленькая выборка | Бутстрап не требует больших данных |
| Нарушены допущения | Не полагается на нормальность |

---

## Ограничения бутстрапа

| Ограничение | Что делать |
|-------------|------------|
| Вычислительно затратен | Уменьшить `n_resamples` (например, 1000 вместо 10000) |
| Зависит от исходной выборки | Чем больше исходная выборка, тем лучше |
| Не работает для экстремальных статистик (максимум, минимум) | Использовать специализированные методы |

---

## Преимущества бутстрапа

| Преимущество | Описание |
|--------------|----------|
| **Непараметрический** | Не требует нормальности распределения |
| **Универсальный** | Работает с любой метрикой |
| **Прозрачный** | Логика интуитивно понятна |
| **Надёжный** | При большом числе симуляций даёт точные результаты |

## Пример: доверительный интервал для медианы

```python
import pandas as pd
import numpy as np

# Исходные данные
np.random.seed(42)
data = pd.Series(np.random.exponential(100, size=100))

# Бутстрап
medians = []
for i in range(10000):
    sample = data.sample(frac=1, replace=True)
    medians.append(sample.median())

# 95% доверительный интервал
ci_lower = np.quantile(medians, 0.025)
ci_upper = np.quantile(medians, 0.975)

print(f"Медиана: {data.median():.2f}")
print(f"95% CI: [{ci_lower:.2f}, {ci_upper:.2f}]")
```
