# Mathematical Statistics Portfolio

## Overview

Этот раздел репозитория содержит конспекты, теоретические материалы и практические задачи по **математической статистике** в рамках курса аналитики данных.

Материалы охватывают полный спектр статистических методов — от базовых понятий до продвинутых техник, используемых в A/B-тестировании, регрессионном анализе и машинном обучении.

Основная цель этого раздела — показать понимание:

- основ статистического вывода
- проверки статистических гипотез
- дисперсионного и регрессионного анализа
- непараметрических методов
- применения статистики в продуктовой аналитике

## Topics Covered

| Тема | Описание |
|------|----------|
| **Основы статистики** | Генеральная совокупность и выборка, типы переменных, меры центральной тенденции и разброса |
| **Схема Бернулли** | Формула Бернулли, решение задач на "ровно k", "не более k", "не менее k" успехов |
| **Формула Байеса** | Условная вероятность, парадокс редкой болезни, полная вероятность |
| **Проверка гипотез** | Z-стандартизация, ЦПТ, p-value, ошибки I и II рода |
| **Статистический вывод** | Доверительные интервалы, скользящее среднее, поиск аномалий во временных рядах |
| **t-тест** | Сравнение средних двух выборок, A/B-тестирование |
| **ANOVA** | Сравнение средних трёх и более групп, множественные сравнения |
| **Корреляция** | Коэффициенты Пирсона, Спирмена, Кендалла |
| **Линейная регрессия** | Простая и множественная регрессия, интерпретация коэффициентов, диагностика модели |
| **Bootstrap** | Непараметрический метод оценки доверительных интервалов для любых метрик |
| **Анализ категориальных переменных** | Хи-квадрат, таблицы сопряженности, фиктивные переменные |

## Skills Demonstrated

В этом разделе демонстрируются следующие навыки статистического анализа:

- **Работа с распределениями:** нормальное, биномиальное, хи-квадрат, t-распределение
- **Точечные и интервальные оценки:** доверительные интервалы для среднего, медианы, квантилей
- **Проверка гипотез:** t-тест, ANOVA, хи-квадрат, p-value, статистическая значимость
- **Регрессионный анализ:** простая и множественная регрессия, интерпретация коэффициентов, мультиколлинеарность
- **Корреляционный анализ:** Пирсон, Спирмен, Кендалл
- **Непараметрические методы:** Bootstrap для любых метрик
- **Категориальный анализ:** таблицы сопряженности, chi-square, one-hot encoding
- **Анализ временных рядов:** скользящее среднее, доверительные интервалы, аномалии
- **A/B-тестирование:** дизайн эксперимента, анализ результатов, выводы для бизнеса
- **Визуализация распределений:** гистограммы, боксплоты, QQ-графики, KDE

## Key Takeaways

| Тема | Ключевой вывод |
|------|----------------|
| **Bootstrap** | Позволяет построить доверительный интервал для любой метрики без готовых формул |
| **Регрессия** | Учитывает уникальный вклад каждой переменной, очищенный от влияния других |
| **ANOVA** | Обобщение t-теста на 3+ группы, требует поправок на множественные сравнения |
| **Хи-квадрат** | Единственный способ проверить связь между категориальными переменными |
| **Доверительный интервал** | Отражает диапазон, в который попадает значение ГС с заданной вероятностью |
| **p-value** | Не равен вероятности того, что гипотеза верна — это вероятность данных при H₀ |
