# Анализ категориальных переменных — Chi-square, таблицы сопряженности, фиктивные переменные

## Теория

### Когда применять

Категориальные данные — это данные, которые делятся на **группы** (категории), а не измеряются числами:

| Пример | Тип категориальной переменной |
|--------|-------------------------------|
| Пол (М/Ж) | бинарная |
| Город (Москва/СПб/Казань) | номинальная (без порядка) |
| Оценка (отлично/хорошо/плохо) | порядковая (есть порядок) |
| Купил / не купил | бинарная (исход) |

Для таких данных **не работают** средние и корреляции — нужны специальные методы.

---

## 1. Критерий Хи-квадрат (χ²) для одной переменной

**Используется для проверки:** соответствует ли категориальная переменная выбранному распределению.

**Пример:** проверка, честная ли игральная кость.

### Условия применения

| Условие | Требование |
|---------|------------|
| Независимость наблюдений | Строгое |
| Количество наблюдений в ячейке | ≥ 10 (или 5–10 с поправкой Йетса) |

### Формула

$$ \chi^2 = \sum_{i=1}^{n} \frac{(N_i - N \cdot p_i)^2}{N \cdot p_i} $$

Где:
- $N_i$ — наблюдаемое количество в i-й категории
- $N$ — общее количество наблюдений
- $p_i$ — ожидаемая вероятность i-й категории
- $N \cdot p_i$ — ожидаемое количество

### Степени свободы

$$ df = n - 1 $$

где $n$ — количество категорий.

### Пример с игральной костью

**Наблюдаемые значения (600 бросков):**

| Грань | 1 | 2 | 3 | 4 | 5 | 6 |
|-------|---|---|---|---|---|---|
| Выпадений | 70 | 110 | 20 | 300 | 40 | 60 |

**Ожидаемые значения (равномерное распределение):**

| Грань | 1 | 2 | 3 | 4 | 5 | 6 |
|-------|---|---|---|---|---|---|
| Выпадений | 100 | 100 | 100 | 100 | 100 | 100 |

**Расчёт:**

$$ \chi^2 = \frac{(70-100)^2}{100} + \frac{(110-100)^2}{100} + ... + \frac{(60-100)^2}{100} = 526 $$

**Вывод:** $df = 5$, критическое значение на уровне 0.05 ≈ 11.1.  
526 > 11.1 → **отвергаем H₀**, кость нечестная.

### Реализация в Python

```python
from scipy.stats import chisquare

observed = [70, 110, 20, 300, 40, 60]
expected = [100] * 6

result = chisquare(observed, expected)
print(result.statistic)  # 526.0
print(result.pvalue)     # ≈ 0.0
```

## 2. Таблицы сопряженности (Contingency Tables)

**Используются для проверки:** есть ли связь между двумя категориальными переменными.

### Пример

Есть приложение для заказа еды в Москве и Петербурге. Проверяем, зависит ли доля пользователей iOS от города.

**Наблюдаемая таблица:**

| Город | iOS | Android | Всего |
|-------|-----|---------|-------|
| Москва | 1000 | 4000 | 5000 |
| СПб | 700 | 1200 | 1900 |
| Всего | 1700 | 5200 | 6900 |

**Ожидаемые значения (при H₀: распределение не зависит от города):**

| Город | iOS | Android |
|-------|-----|---------|
| Москва | 1232 | 3768 |
| СПб | 468 | 1432 |

**Расчёт χ²:**

$$ \chi^2 = \frac{(1000-1232)^2}{1232} + ... = 215.32 $$

**Степени свободы:**

$$ df = (n-1)(m-1) = (2-1)(2-1) = 1 $$

**Вывод:** статистика > критического значения → **распределение iOS/Android зависит от города**.

### Реализация в Python

```python
import pandas as pd
from scipy.stats import chi2_contingency

data = pd.DataFrame({
    'iOS': [1000, 700],
    'Android': [4000, 1200]
}, index=['Москва', 'СПб'])

chi2, pval, dof, expected = chi2_contingency(data)
print(f"χ² = {chi2:.2f}, p-value = {pval:.4f}, dof = {dof}")
```

**Создание таблицы сопряженности из данных:**

```python
# Из датафрейма
contingency = pd.crosstab(df['city'], df['os'])
chi2_contingency(contingency)
```

## 3. Кодирование фиктивных переменных (Dummy Variables)

### Зачем нужно

Категориальные переменные нужно преобразовать в числа, чтобы использовать в регрессии.

### One-hot Encoding

Каждая категория становится отдельным столбцом (0/1).

| Животное | кошка | собака | крыса |
|----------|-------|--------|-------|
| кошка | 1 | 0 | 0 |
| собака | 0 | 1 | 0 |
| крыса | 0 | 0 | 1 |

```python
# pandas
pd.get_dummies(df['animal'])

# sklearn
from sklearn.preprocessing import OneHotEncoder
encoder = OneHotEncoder()
encoder.fit_transform(df[['animal']])
```

## 4. Ловушка фиктивных переменных (Dummy Variable Trap)

### Проблема

Если включить все фиктивные переменные в регрессию, возникает **идеальная мультиколлинеарность** — коэффициенты становятся неопределёнными.

### Почему

Между фиктивными переменными идеальная отрицательная корреляция. Если вы знаете, что объект — не кошка и не собака, он автоматически крыса.

### Решение

Удалить **одну** фиктивную переменную.

```python
pd.get_dummies(df['animal'], drop_first=True)
```

| собака | крыса |
|--------|-------|
| 0 | 0 |
| 1 | 0 |
| 0 | 1 |

## 5. Интерпретация фиктивных переменных в регрессии

### Модель

$$ \text{вредность} = \beta_0 + \beta_1 \cdot \text{собака} + \beta_2 \cdot \text{крыса} $$

**Пример коэффициентов:**

$$ \text{вредность} = 20.15 - 10.8 \cdot \text{собака} + 2.5 \cdot \text{крыса} $$

### Интерпретация

| Коэффициент | Что значит |
|-------------|------------|
| $\beta_0 = 20.15$ | Средняя вредность **кошек** (выкинутая категория) |
| $\beta_1 = -10.8$ | Собаки на 10.8 ед. **менее** вредны, чем кошки |
| $\beta_2 = 2.5$ | Крысы на 2.5 ед. **более** вредны, чем кошки |

### Важный вывод

Регрессия с фиктивными переменными **математически эквивалентна**:
- t-тесту (для 2 групп)
- ANOVA (для 3+ групп)
- Дисперсионному анализу

## Связь с другими методами

| Метод | Эквивалент в регрессии |
|-------|------------------------|
| t-тест | Регрессия с одной бинарной фиктивной переменной |
| Однофакторный ANOVA | Регрессия с несколькими фиктивными переменными |
| Хи-квадрат | Логистическая регрессия (для бинарного исхода) |

## Полный пайплайн в Python

```python
import pandas as pd
from scipy.stats import chisquare, chi2_contingency

# 1. Проверка одной переменной
observed = df['category'].value_counts()
expected = [len(df) / len(observed)] * len(observed)
chisquare(observed, expected)

# 2. Проверка связи двух переменных
contingency = pd.crosstab(df['var1'], df['var2'])
chi2_contingency(contingency)

# 3. Подготовка для регрессии
dummies = pd.get_dummies(df['category'], drop_first=True)
```
