# A/B-тест нового алгоритма доставки

Учебный проект по анализу результатов A/B-теста из курса **Karpov.Courses**.

## Бизнес-задача

Вечером доставка замедляется: часть курьеров завершает смену, тогда как поток заказов сохраняется. Проверяется алгоритм, который позволяет учитывать маршрут курьера домой при назначении последних заказов.

**Вопрос:** изменилось ли среднее время доставки при использовании нового алгоритма?

- **Control:** прежний алгоритм.
- **Test:** новый алгоритм.
- **Основная метрика:** `delivery_time` — время доставки заказа в минутах (меньше — лучше).

## Данные

В файле `experiment_lesson_4.csv` — **20 196 строк** с полями `order_id`, `delivery_time`, `district`, `experiment_group`.

| Группа | Количество наблюдений | Стандартное отклонение времени доставки, мин |
|---|---:|---:|
| Control | 10 092 | 9,9900 |
| Test | 10 104 | 9,8833 |

Разница размеров групп — **12** наблюдений. Количества групп восстановлены из сохранённых результатов ноутбука: всего 20 196 наблюдений, `test − control = 12`.

## Подход

1. Загрузил результаты эксперимента с помощью Pandas и изучил структуру данных.
2. Визуализировал распределение `delivery_time` в группах с разбивкой по районам (`district`).
3. Проверил нормальность распределений тестом Д’Агостино—Пирсона (`scipy.stats.normaltest`): в тесте `p ≈ 0,0298`, в контроле `p ≈ 0,8810`. Формально нормальность в тестовой группе отвергается на уровне 5%; при большом размере выборок t-тест средних может быть достаточно устойчивым при выполнении остальных предпосылок.
4. Сравнил средние времени доставки независимым двухвыборочным t-тестом Стьюдента (`scipy.stats.ttest_ind`).
5. Рассчитал относительное изменение среднего времени доставки: `(test.mean() / control.mean() - 1) * 100`.

## Результаты

- **t-статистика:** −43,0358 (`df = 20 194`).
- **p-value:** очень мало, **меньше 0,001**. В сохранённом выводе SciPy отображается `0.0` из-за ограничения численного представления очень малых вероятностей; это не означает, что математически p-value в точности равно нулю.
- **Изменение среднего времени доставки:** **−13,35%** в тестовой группе относительно контрольной.

При использованном тесте различие средних статистически значимо. В учебных данных новый алгоритм ассоциирован с меньшим средним временем доставки.

## Вывод и ограничения

Результат поддерживает дальнейшее внедрение/проверку нового алгоритма. Перед масштабированием в реальном продукте необходимо проверить качество рандомизации и независимость наблюдений, а также дополнительные метрики — например, долю доставок с опозданием, удовлетворённость клиентов и нагрузку на курьеров. Если рандомизация проводилась на уровне курьера, а анализ сделан по заказам, нужно отдельно учитывать возможную зависимость заказов одного курьера.
