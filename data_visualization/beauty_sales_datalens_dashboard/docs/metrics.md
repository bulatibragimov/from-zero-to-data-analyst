# Метрики и формулы в Yandex DataLens

Расчёты использованы в учебном проекте на данных за 2023 год. `Dynamic` и `Product` — **разные датасеты**. Формулы записаны в синтаксисе вычисляемых полей DataLens.

## Выручка за выбранный месяц (`Dynamic`)

```sql
SUM([Выручка])
```

Отображение в млрд ₽: `SUM([Выручка]) / 1000000000`.

## Продажи за выбранный месяц (`Dynamic`)

```sql
SUM([Продажи])
```

Отображение в млн шт.: `SUM([Продажи]) / 1000000`.

## Взвешенный процент выкупа (`Dynamic`)

```sql
SUM([Продажи] * [Средний % выкупа]) / SUM([Продажи]) * 100
```

Используется вес по количеству продаж/заказов. Доля исходно лежит в диапазоне 0–1.

## Средняя цена за декабрь (`Product`)

Вычисляемое поле по строке товара:

```sql
[Цена (Декабрь)] * [Продажи (Декабрь)]
```

Затем:

```sql
SUM([Стоимость продаж (декабрь)]) / SUM([Продажи (Декабрь)])
```

## Рост выручки MoM (`Product`)

```sql
IF(
    SUM([Выручка (Ноябрь)]) = 0,
    NULL,
    (SUM([Выручка (Декабрь)]) / SUM([Выручка (Ноябрь)]) - 1) * 100
)
```

## Недобор бренда до плана +5%, млн ₽ (`Product`)

```sql
(SUM([Выручка (Ноябрь)]) * 1.05 - SUM([Выручка (Декабрь)])) / 1000000
```

Положительное значение — ниже планового уровня; отрицательное — план выполнен. Для ТОП-10 применён ранг по убыванию недобора и фильтрация положительных значений.

## Выкуп по категории (`Product`)

```sql
SUM([Продажи (Декабрь)] * [Средний % выкупа (Декабрь)])
/ SUM([Продажи (Декабрь)]) * 100
```

## Проблемные SKU

Для таблицы с уровнем SKU показатель выкупа округлён до двух знаков **в формуле**, чтобы убрать эффект двоичной погрешности на пороге 95%:

```sql
ROUND(
    SUM([Продажи (Декабрь)] * [Средний % выкупа (Декабрь)])
    / SUM([Продажи (Декабрь)]) * 100,
    2
)
```

Фильтры: выкуп `< 95` и продажи `> 0`. Добавлено сравнение выручки декабря с ноябрём на уровне SKU.

## Периоды и управление фильтрами

- Селектор `Отчётный месяц` изменяет KPI выручки, продаж и выкупа из `Dynamic`; шестимесячный тренд не ограничивается одним месяцем.
- Цена и MoM сравниваются за фиксированные ноябрь и декабрь 2023 года.
- Селекторы категории, бренда, страны действуют на соответствующие графики `Product` и SKU-таблицу.
