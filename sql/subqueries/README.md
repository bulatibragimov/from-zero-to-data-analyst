# SQL: подзапросы и CTE — аналитические задачи

**PostgreSQL · практика на учебном датасете Karpov.Courses**

Файл [subqueries_queries.sql](subqueries_queries.sql) содержит 10 решений: вложенные запросы в `WHERE`, сравнительные агрегаты, `IN`, `EXISTS`, `CTE` и `CASE`.

## Наиболее показательные решения

| № в файле | Аналитическая задача | Приёмы | Код |
|---|---|---|---|
| 6 | Сегментация клиентов по числу просмотров страниц | `WITH`, `COUNT() FILTER`, `CASE` | [Решение](subqueries_queries.sql#L163-L192) |
| 7 | Найти клиентов, просматривавших страницы, но не совершивших доставленных заказов | Вложенные `IN` / `NOT IN` | [Решение](subqueries_queries.sql#L195-L219) |
| 10 | Классификация клиентов по дате первого заказа | `WITH`, `MIN`, `CASE` | [Решение](subqueries_queries.sql#L280-L306) |
| 8 | Найти бренды со средней ценой выше средней по всем проданным товарам на 20% | `JOIN`, `HAVING`, скалярный подзапрос | [Решение](subqueries_queries.sql#L222-L243) |
| 5 | Найти категории товаров, которые встречались хотя бы в одном заказе | Коррелированный `EXISTS` | [Решение](subqueries_queries.sql#L141-L159) |

В полном файле также есть сравнение агрегатов категории с общим средним, поиск самой дорогой позиции заказа и вложенная фильтрация по городам покупателей.

> Запросы представлены как учебные решения. Для повторного выполнения нужна учебная база. В частности, для переноса сценариев с `NOT IN` в другие датасеты следует отдельно учитывать возможные `NULL` в подзапросе.
