# Анализ оптовых продаж аудиотехники

Учебный аналитический проект в рамках курса **Karpov.Courses**.

В проекте исследуются данные оптовой компании по продаже аудиотехники.  
Исходные данные были распределены по нескольким директориям и файлам, поэтому перед анализом их необходимо было собрать, объединить и подготовить.

## Цель проекта

На основе данных о заказах, товарах, клиентах и менеджерах:

- собрать данные из разрозненных источников;
- рассчитать ключевые метрики продаж;
- исследовать аномалии в динамике заказов;
- определить наиболее значимые бренды;
- проанализировать востребованность ассортимента;
- оценить результаты работы менеджеров.

## Данные

Использовались три основных набора данных:

- **orders** — товары и их количество в заказах;
- **order_status** — клиенты и статусы заказов;
- **products** — названия, категории и цены товаров.

Дополнительно использовались данные о курсе доллара для пересчёта стоимости заказов в рубли.

Размер исходных таблиц:

| Таблица | Количество строк |
|---|---:|
| Orders | 4 603 |
| Order status | 346 |
| Products | 1 677 |

## Что было сделано

### 1. Сбор и подготовка данных

- автоматически собрал файлы из вложенной структуры директорий с помощью `os.walk()`;
- объединил данные в единые DataFrame;
- добавил информацию о дате, менеджере и категории товара;
- преобразовал типы данных и подготовил таблицы к анализу;
- объединил заказы, статусы, товары и курсы валют с помощью `merge()`.

### 2. Анализ динамики заказов

Исследовал количество заказов по дням и их статусы.

В данных обнаружена аномалия:

- **9 марта** в сохранённом расчёте не оказалось подтверждённых заказов;
- **14 марта** наблюдался пик числа уникальных заказов.

Отдельно исследованы отменённые заказы **13 марта** и подтверждённые заказы **14 марта**.

Для проверки гипотезы о повторном оформлении заказов сопоставил отменённые заказы 13 марта с подтверждёнными заказами 14 марта по клиенту, менеджеру, количеству уникальных товаров и общему количеству товаров.

**Результат сопоставления: 0,47** — отношение числа строк совпадений после `merge()` к числу подтверждённых заказов 14 марта. Сопоставлялись клиент, менеджер, число уникальных товаров и суммарное количество товаров. Это совпадение агрегированных характеристик, а не доказательство идентичности корзины или факта переоформления. Для более строгого вывода следует проверить уникальность ключей соединения.

Полученное совпадение согласуется с гипотезой о повторном оформлении части заказов, однако само по себе не устанавливает причину наблюдаемой динамики.

### 3. Расчёт ключевых метрик

Для подтверждённых заказов рассчитал:

| Метрика | Значение |
|---|---:|
| Общая выручка | 2 038 231 821,56 ₽ |
| Средний чек | 6 596 219,49 ₽ |

Также исследовал дневную динамику:

- количества заказов;
- выручки;
- среднего чека.

Для визуализации использовал линейные графики.

### 4. Анализ брендов

Из названий товаров выделил бренды и проанализировал их вклад в продажи.

- в данных представлено **121 бренд**;
- **JBL** принёс наибольшую выручку среди брендов;
- сравнил бренды по объёму продаж и количеству заказанных товаров.

### 5. Анализ ассортимента

Проверил, какие товары хотя бы один раз попадали в подтверждённые заказы:

| Статус товара | Количество |
|---|---:|
| Заказывались | 1 180 |
| Не заказывались | 497 |

Около **30% ассортимента** не было заказано ни разу за рассматриваемый период.

Среди брендов с достаточно широким ассортиментом (не менее 15 товаров) доля незаказанных товаров превышала 50% у:

- Dali;
- KEF;
- Marantz;
- Pioneer.

Это может быть сигналом для дополнительного анализа ассортимента и товарных запасов.

### 6. Анализ работы менеджеров

Для каждого менеджера рассчитал:

- выручку;
- количество строк товарных позиций в подтверждённых заказах;
- долю от общей выручки;
- долю от общего числа таких строк (не уникальных заказов).

Лидером стала **Маргарита Камертонова**:

- **17,04%** общей выручки;
- **16,61%** строк товарных позиций в подтверждённых заказах.

Результаты были визуализированы с помощью столбчатых диаграмм.

## Основные выводы

1. В сохранённом расчёте 9 марта отсутствовали подтверждённые заказы; 14 марта наблюдался пик числа заказов.
2. Сопоставление агрегированных признаков отменённых заказов 13 марта и подтверждённых 14 марта дало показатель 0,47 (строки соединения / подтверждённые заказы 14 марта); результат не доказывает фактическое переоформление.
3. Общая выручка за анализируемый период составила около **2,04 млрд ₽**.
4. JBL оказался лидером по выручке среди анализируемых брендов.
5. **497 из 1 677 товаров** не были заказаны ни разу, что указывает на потенциальную возможность оптимизации ассортимента.
6. Маргарита Камертонова показала наибольшую долю выручки и строк товарных позиций среди подтверждённых заказов.

```text

    │       └── order_status.csv
    └── products/
        └── <категория>/products.csv
```

Запускайте Jupyter из папки проекта. В опубликованном ноутбуке сохранены результаты предыдущего выполнения. Исходный учебный датасет в приложенных файлах отсутствует.

**Примечание:** для доли 0,47 в коде используется `len(repeat_orders) / len(confirmed_2024_03_14)`. Если одному подтверждённому заказу соответствует несколько совпадений, следует дополнительно считать число уникальных `order_id_x`.
