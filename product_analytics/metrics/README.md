# Метрики продукта

## Теория

### Виды метрик

| Тип метрик | Что показывают | Примеры |
|------------|----------------|---------|
| **Метрики роста бизнеса** | Финансовые результаты продукта | Выручка, прибыль, маржинальность |
| **Метрики продукта** | Качество продукта и помогают принимать продуктовые решения | Retention, Conversion Rate, DAU/MAU |

---

## Метрики продукта по этапам клиентского пути

Клиент проходит через разные этапы взаимодействия с продуктом. На каждом этапе важна **своя метрика**, которая точно отражает клиентский опыт.

### Основные этапы и метрики

| Этап | Описание | Пример метрики |
|------|----------|----------------|
| **Привлечение** | Пользователь узнал о продукте | Количество визитов, CAC |
| **Активация** | Пользователь получил первую ценность | Activation Rate, % регистраций |
| **Удержание** | Пользователь возвращается | Retention Rate, Churn Rate |
| **Монетизация** | Пользователь приносит доход | ARPU, LTV, Средний чек |
| **Реферал** | Пользователь рекомендует | NPS, Viral Coefficient |

## Retention — главная метрика продукта

**Retention** позволяет оценить наличие **Product/Market Fit**.

### Виды Retention

| Вид | Описание |
|-----|----------|
| **N-day retention** | % пользователей, вернувшихся на N-й день после регистрации |
| **Rolling retention** | % пользователей, активных в течение N дней после регистрации |

### Гранулярность Retention

| Гранулярность | Описание | Когда использовать |
|---------------|----------|---------------------|
| **D1, D3, D7** | Возврат через 1, 3, 7 дней | Быстрая оценка продукта |
| **D30, D60** | Возврат через месяц, два | Оценка долгосрочного удержания |
| **Weekly / Monthly** | Возврат за неделю / месяц | Продукты с низкой частотой использования |

### Почему Retention важна?

- Если пользователи не возвращаются → продукт не решает их задачу
- Если retention стабилизируется на уровне → есть PMF
- Если retention постоянно падает к нулю → PMF нет

## Дерево метрик (Metric Tree)

**Дерево метрик** — способ систематизировать точки влияния на основную метрику бизнеса.

### План построения дерева метрик

| Шаг | Действие |
|-----|----------|
| **Шаг 1** | Определите основную верхнеуровневую метрику |
| **Шаг 2** | Декомпозируйте основную метрику на метрики, перемножив которые мы сможем её получить |
| **Шаг 3** | Повторяйте до тех пор, пока не будет достаточного уровня детализации |

### Пример дерева метрик для e-commerce

```
Выручка
    ↓
Количество заказов × Средний чек
    ↓
Количество пользователей × Конверсия в заказ × Средний чек
    ↓
Новые × Конверсия + Старые × Конверсия
```

### Зачем нужно дерево метрик?

| Задача | Как помогает дерево метрик |
|--------|----------------------------|
| Поиск точек роста | Показывает, какие метрики влияют на главную |
| Приоритизация гипотез | Помогает понять, где изменение даст наибольший эффект |
| Мониторинг здоровья продукта | Позволяет отслеживать изменения на разных уровнях |
| Коммуникация с командой | Даёт общее понимание бизнес-модели |

## Сравнение метрик роста бизнеса и метрик продукта

| Критерий | Метрики роста бизнеса | Метрики продукта |
|----------|------------------------|------------------|
| **Цель** | Оценить финансовый результат | Оценить качество продукта |
| **Аудитория** | Руководство, инвесторы | Продукт-команда |
| **Примеры** | Выручка, прибыль, ROI | Retention, DAU/MAU, NPS |
| **Что показывают** | Сколько денег заработали | Насколько продукт полезен пользователям |
| **Действие** | Принимать бизнес-решения | Принимать продуктовые решения |
