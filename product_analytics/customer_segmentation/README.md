# Методы сегментации клиентов

## Теория

### Зачем нужна сегментация?

Клиенты продукта имеют разные потребности и требуют индивидуального подхода.

**Сегментация** позволяет выделять группы клиентов по параметрам, чтобы учитывать их особенности.

### Почему анализ без сегментации опасен?

| Риск | Описание |
|------|----------|
| **Скрытые изменения** | Общий анализ может маскировать важные изменения в продукте |
| **Упущенные возможности** | Небольшие сегменты незаметны в общей статистике |
| **Компенсация сегментов** | Один сегмент компенсирует падение другого, создавая иллюзию стабильности |
| **Ориентация на "среднего"** | Разработка продукта, неудобного для реальных пользователей |

### Цели сегментации

| Цель | Что даёт |
|------|----------|
| **Персонализация** | Адаптация продукта под разные группы |
| **Анализ вкладов когорт** | Понимание, какие сегменты приносят доход |
| **Оптимизация поведения** | Стимулирование нужных действий |

## RFM-сегментация

**RFM** — метод сегментации клиентов по трём параметрам:

| Параметр | Описание | Вопрос |
|----------|----------|--------|
| **R — Recency** | Давность последнего действия | Как давно клиент взаимодействовал с продуктом? |
| **F — Frequency** | Частота действий | Как часто клиент взаимодействует с продуктом? |
| **M — Monetary** | Объём / ценность | Какую ценность приносит клиент? |

### Применение RFM

RFM-сегментация выделяет группы для:
- Персонализации продукта
- Таргетированного маркетинга
- Удержания ценных клиентов
- Реактивации "спящих" пользователей

## Правила формирования RFM-кластеров в кейсе

### Recency (R)

| Условие | Оценка |
|---------|--------|
| `recency ≤ медиана` | `2` |
| `recency > медиана` | `1` |

### Frequency (F)

| Условие | Оценка |
|---------|--------|
| `frequency < 50%` | `1` |
| `50% ≤ frequency < 100%` | `2` |
| `frequency ≥ 100%` | `3` |

### Monetary (M)

| Условие | Оценка |
|---------|--------|
| `monetary < 40` | `1` |
| `40 ≤ monetary ≤ 80` | `2` |
| `monetary > 80` | `3` |

### Формирование кластера

```python
rfm_cluster = str(R) + str(F) + str(M)
```
