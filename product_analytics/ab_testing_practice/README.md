# A/B-тесты: практика выбора метрик

## Теория

### Какие метрики подходят для A/B-тестов?

Не каждая метрика подходит для проведения A/B-эксперимента.

**Три ключевых свойства метрики для A/B-теста:**

| Свойство | Что значит | Почему важно |
|----------|------------|---------------|
| **Чувствительность** | Метрика быстро реагирует на изменения | Чтобы увидеть эффект за разумное время |
| **Достоверность** | Метрика объективно отражает изменения | Чтобы доверять результатам |
| **Интерпретируемость** | Метрика понятна команде | Чтобы принимать решения |

---

### Почему метрики роста не подходят для A/B-тестов

| Метрика роста | Проблема | Пример |
|---------------|----------|--------|
| **Выручка** | Долго меняется, много шума | Эксперимент может длиться месяцы |
| **Количество пользователей** | Зависит от внешних факторов | Трудно изолировать эффект |
| **Доля рынка** | Меняется очень медленно | Не чувствительна к изменениям |

**Главная проблема:** метрики роста не чувствительны, и с ними эксперимент будет длиться слишком долго.

---

## Дерево метрик для A/B-тестов

Для выбора метрик эксперимента используют **дерево метрик**. В A/B-тестах выделяют три типа метрик:

| Тип метрики | Описание | Пример |
|-------------|----------|--------|
| **Целевая метрика** | Основная метрика, на которую влияет изменение | Конверсия в покупку, Retention |
| **Прокси-метрика** | Быстро отражает эффект, коррелирует с целевой | CTR, время на странице |
| **Барьерная метрика** | Показывает негативные последствия | Отказы, жалобы, Churn |

### Зачем нужны три типа метрик?

| Тип | Зачем |
|-----|-------|
| **Целевая** | Оценить успех изменения |
| **Прокси** | Быстро понять направление эффекта |
| **Барьерная** | Вовремя заметить негативные последствия |

---

## Иерархия метрик в A/B-тесте

```
Целевая метрика (главная)
    ↑
Прокси-метрика (быстрый сигнал)
    ↑
Барьерная метрика (защита от негатива)
```

### Пример для e-commerce

| Тип | Метрика | Почему |
|-----|---------|--------|
| **Целевая** | Конверсия в покупку | Изменение влияет на бизнес |
| **Прокси** | Добавление в корзину | Быстрый сигнал, коррелирует с покупкой |
| **Барьерная** | Жалобы в поддержку | Чтобы не ухудшить опыт |

### Пример для мобильного приложения

| Тип | Метрика | Почему |
|-----|---------|--------|
| **Целевая** | Retention (D7) | Долгосрочная ценность |
| **Прокси** | Время в приложении | Быстрый сигнал вовлечённости |
| **Барьерная** | Количество вылетов (crashes) | Чтобы не сломать продукт |

## Как выбирать метрики для A/B-теста

### Шаг 1. Определите бизнес-цель

> Что мы хотим улучшить?

### Шаг 2. Выберите целевую метрику

> Какая метрика лучше всего отражает эту цель?

### Шаг 3. Выберите прокси-метрику

> Какая метрика даст быстрый сигнал?

### Шаг 4. Выберите барьерную метрику

> Что может пойти не так? Как это измерить?

---

## Рекомендация по выбору метрик

> **Для эксперимента выбирайте хотя бы одну метрику каждого вида: целевую, прокси и барьерную.**

**Почему:**

| Преимущество | Объяснение |
|--------------|------------|
| **Оценка успеха** | Целевая метрика показывает, сработало ли изменение |
| **Быстрая реакция** | Прокси-метрика даёт сигнал до завершения эксперимента |
| **Защита от негатива** | Барьерная метрика предотвращает катастрофу |

---

## Ошибки при выборе метрик для A/B-теста

| Ошибка | Пример | Как избежать |
|--------|--------|---------------|
| **Только одна метрика** | Смотрим только на выручку | Добавить прокси и барьерную |
| **Метрика роста** | Выручка за месяц | Использовать чувствительные метрики |
| **Сложная интерпретация** | Сложный составной индекс | Использовать понятные метрики |
| **Нет барьерной метрики** | Упустили падение качества | Всегда добавлять барьерную |

## Ключевые выводы

| Понятие | Суть |
|---------|------|
| **Чувствительность** | Метрика должна быстро реагировать на изменения |
| **Достоверность** | Метрика должна объективно отражать изменения |
| **Интерпретируемость** | Метрика должна быть понятна команде |
| **Целевая метрика** | Основная, показывает успех изменения |
| **Прокси-метрика** | Быстрый сигнал, коррелирует с целевой |
| **Барьерная метрика** | Защищает от негативных последствий |
| **Правило** | Минимум 3 метрики: целевая + прокси + барьерная |
