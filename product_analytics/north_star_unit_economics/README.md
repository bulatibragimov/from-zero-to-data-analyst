# Масштабирование, юнит-экономика и метрика North Star

## Теория

### Юнит-экономика

**Юнит-экономика** — это оценка прибыли, которую продукт получает с одного юнита (например, клиента, заказа, пользователя).

Юнит-экономика помогает ответить на вопрос:

> **«Прибыльны ли мы на уровне одного клиента или сделки?»**

### Основные метрики юнит-экономики

| Метрика | Описание |
|---------|----------|
| **LTV (Lifetime Value)** | Прибыль за всю жизнь клиента |
| **CAC (Customer Acquisition Cost)** | Средние затраты на привлечение клиента |
| **CPA (Cost Per Acquisition)** | Стоимость привлечения одного платящего пользователя |
| **Рентабельность юнита** | LTV - CAC (или LTV / CAC) |

### Формула юнит-экономики

$$ \text{Unit Profit} = LTV - CAC $$

**Признак устойчивости бизнеса:**

$$ LTV > CAC $$

### Как считается юнит-экономика

Юнит-экономика обычно считается **по конкретной когорте** (группе пользователей, объединённых по времени регистрации или первому действию).

**Пример:** когорта пользователей, зарегистрировавшихся в январе 2024 года. Для них считается средний LTV и средний CAC.

---

## LTV (Lifetime Value)

**LTV** — это прибыль, которую компания получает от одного клиента за всё время его взаимодействия с продуктом.

### Формулы расчёта LTV

| Способ | Формула | Когда использовать |
|--------|---------|---------------------|
| **Простой** | LTV = Средний доход с клиента за период × Количество периодов | Для продуктов с подпиской |
| **Через Retention** | LTV = ARPU × (1 / Churn Rate) | Для продуктов с регулярными платежами |
| **Через средний чек** | LTV = Средний чек × Частота покупок × Время жизни | Для e-commerce |

### Пример

Если клиент платит 1000 руб. в месяц и остаётся в среднем 12 месяцев, то:

$$ LTV = 1000 \times 12 = 12 000 \text{ руб.} $$

---

## CAC (Customer Acquisition Cost)

**CAC** — это средние затраты на привлечение одного платящего клиента.

### Формула

$$ CAC = \frac{\text{Общие затраты на маркетинг и продажи за период}}{\text{Количество новых клиентов за период}} $$

### Важные нюансы

- В затраты включаются все маркетинговые каналы
- Для разных каналов CAC может сильно отличаться
- Для подписных продуктов учитываются только платящие пользователи

---

## Юнит-экономика для масштабирования

### Зачем нужна юнит-экономика при масштабировании?

| Вопрос | Ответ |
|--------|-------|
| Можем ли мы масштабироваться? | Если LTV > CAC, то каждый новый клиент приносит прибыль |
| Сколько можно тратить на маркетинг? | Не больше LTV |
| Какой канал самый эффективный? | Где LTV/CAC выше |

### Пример оценки масштабирования

| Канал | LTV | CAC | LTV/CAC | Прибыль с клиента |
|-------|-----|-----|---------|-------------------|
| SEO | 5000 | 1000 | 5.0 | 4000 |
| Контекстная реклама | 4500 | 1500 | 3.0 | 3000 |
| SMM | 4200 | 2000 | 2.1 | 2200 |

**Вывод:** SEO — самый эффективный канал для масштабирования.

## North Star — главная метрика продукта

**North Star** — метрика, которая позволяет координировать действия всей компании и направлять их на достижение желаемых результатов.

### Суть North Star

**North Star отражает объём ценности, которую клиенты получают во время пользования продуктом.**

### Примеры North Star

| Продукт | North Star метрика |
|---------|-------------------|
| Spotify | Количество прослушанных минут |
| Uber | Количество завершённых поездок |
| Airbnb | Количество забронированных ночей |
| Facebook | Количество активных пользователей (DAU) |
| Slack | Количество отправленных сообщений |

### Свойства North Star

| Свойство | Описание |
|----------|----------|
| **Отражает ценность** | Показывает, сколько ценности получают пользователи |
| **Измерима** | Можно объективно посчитать |
| **Влияет на бизнес** | Рост метрики → рост бизнес-результатов |
| **Понятна всем** | Вся команда понимает, что она означает |
| **Действенна** | Команда может влиять на неё |

### North Star vs KPI

| Критерий | North Star | KPI |
|----------|------------|-----|
| **Уровень** | Стратегический | Тактический |
| **Аудитория** | Вся компания | Отдельные команды |
| **Фокус** | Долгосрочная ценность | Краткосрочные цели |
| **Количество** | 1–2 | Много |

### Как North Star помогает компании

| Задача | Как помогает North Star |
|--------|-------------------------|
| Координация команд | Все работают в одном направлении |
| Приоритизация | Какая гипотеза важнее? |
| Связь с бизнесом | Понятно, как продукт создаёт ценность |
| Культура | Команды концентрируются на пользователе |

---

## Связь North Star и юнит-экономики

| Северная звезда | Юнит-экономика |
|-----------------|----------------|
| Отражает ценность для пользователя | Отражает прибыль для бизнеса |
| Метрика продукта | Метрика бизнеса |
| Долгосрочный фокус | Краткосрочная оценка |
| Пример: прослушанные минуты | Пример: LTV - CAC |

**Как они связаны:**

> Если пользователи получают больше ценности (растёт North Star), они дольше остаются в продукте → растёт LTV → улучшается юнит-экономика.

---

## Практический пример: доставка еды

| Компонент | Пример |
|-----------|--------|
| **North Star** | Количество заказов в месяц |
| **LTV** | 2500 руб. (средний чек × частота × месяцы) |
| **CAC** | 1500 руб. |
| **Юнит-экономика** | 2500 - 1500 = 1000 руб. прибыли с клиента |

**Вывод:** можно масштабироваться, так как каждый клиент приносит прибыль.

---

## Ключевые выводы

| Понятие | Суть |
|---------|------|
| **Юнит-экономика** | Оценка прибыли с одного юнита (клиента) |
| **LTV** | Прибыль за всю жизнь клиента |
| **CAC** | Стоимость привлечения клиента |
| **North Star** | Главная метрика, отражающая ценность для пользователей |
| **Связь** | North Star растёт → LTV растёт → бизнес устойчив |
