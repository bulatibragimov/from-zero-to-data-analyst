# Основы продуктовой аналитики

## Теория

### Что такое цифровой продукт?

**Цифровой продукт** — это продукт, который помогает людям решать задачи и удовлетворять потребности в цифровом виде.

Примеры: мобильные приложения, веб-сервисы, SaaS-платформы, онлайн-сервисы.

---

### Продуктовый подход

Продуктовый подход — это способ развития цифровых продуктов, который помогает создавать продукты, приносящие **пользу людям и бизнесу**.

**Три ключевых направления развития продукта:**

| Направление | Что значит |
|-------------|------------|
| Решение задачи клиента | Продукт должен закрывать реальную потребность |
| Повышение эффективности | Решать задачу быстрее, проще, удобнее |
| Создание добавочной ценности | Давать больше, чем просто решение задачи |

---

### Product/Market Fit (PMF)

**Product/Market Fit** — момент, когда продукт **закрывает потребности клиента** и **создаёт добавочную ценность**.

**Когда наступает PMF:**
- Продукт нужен людям
- Люди готовы платить / использовать регулярно
- Продукт решает проблему лучше альтернатив

**Важно:** PMF обязательно должен быть на этапе **старта продукта** для максимизации продаж.

**Как усилить PMF:** научиться **эффективнее решать задачу клиента**.

---

### Jobs To Be Done (JTBD)

**JTBD** — фреймворк для поиска задач клиента и улучшения продукта.

**Основная идея:** люди "нанимают" продукты, чтобы выполнить определённую "работу" (job).

**Пример:**

| Продукт | Задача клиента (Job) |
|---------|---------------------|
| Такси | "Добраться из точки А в точку Б" |
| Доставка еды | "Получить готовую еду без готовки" |
| Банковское приложение | "Управлять деньгами без похода в банк" |

**Как использовать:** 
- Понять, какую именно задачу решает пользователь
- Найти способы решить её лучше, быстрее, удобнее
- Улучшать продукт в направлении этой задачи

---

### HADI-цикл (Hypothesis — Action — Data — Insight)

**HADI-цикл** — это процесс проверки гипотез для развития продукта.

| Этап | Описание |
|------|----------|
| **Hypothesis** | Формулируем гипотезу: "Если — То — Потому что" |
| **Action** | Проводим эксперимент (A/B-тест, запуск фичи) |
| **Data** | Собираем данные, измеряем эффект |
| **Insight** | Анализируем результат, принимаем решение |

---

### Роль аналитика в проверке гипотез

| Что делает аналитик | Зачем |
|---------------------|-------|
| Помогает приоритизировать гипотезы | Оценить ожидаемый эффект и сложность |
| Собирает и анализирует данные | Объективно измерить результат эксперимента |
| Формулирует выводы | Принять решение: внедрять/не внедрять |
